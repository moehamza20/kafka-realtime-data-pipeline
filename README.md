# Kafka Real-Time Data Pipeline

## Overview

A real-time data streaming project built using Apache Kafka, PostgreSQL, Python, and Streamlit.

The system continuously streams data through Kafka topics, consumes messages in real time, stores them in PostgreSQL, and visualizes updates instantly through a Streamlit dashboard.

## Features

* Kafka Producer
* Kafka Consumer
* Real-Time Data Streaming
* PostgreSQL Storage
* Streamlit Dashboard
* Auto-Refresh Visualization
* Live Data Updates

## Technologies Used

* Apache Kafka
* Python
* PostgreSQL
* Streamlit
* SQL

## Workflow

1. Producer publishes messages to Kafka topics.
2. Consumer subscribes to Kafka topics.
3. Incoming records are processed and inserted into PostgreSQL.
4. Streamlit automatically refreshes and displays new records in real time.
